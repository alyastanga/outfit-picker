# Outfit Picker

Upload clothing photos you do not have access to, then dress a **2D mannequin** with them.

## Quick start

```bash
npm install
npm run dev
```

1. Click **Add example clothes** (or upload your own).
2. Tap items in the wardrobe to wear them.
3. Optionally adjust height / body type.

## What this is

**Layer compositing MVP** — garments are placed in fixed slots on a silhouette. Not photoreal AI try-on.

See [ASSIGNMENT.md](./ASSIGNMENT.md) for strategy, model requirements, clarifying questions, and how to use Cursor subagents.
